# Noob Topup — Master Push Notification Admin Console

A dedicated, sleek SaaS Admin Console for broadcasting push notifications, diamond flash deals, and alerts to all users who have installed the Noob Topup Android App.

## Features
- **Live Smartphone Mockup**: Real-time notification preview simulating native Android lock screen / notification drawer.
- **1-Click Deal Presets**: Diamond offers, weekly memberships, airdrop topups, and bonus promotions.
- **OneSignal & FCM Integration**: Broadcasts instant push notifications to all active Android subscribers.
- **Broadcast History**: Automatically tracks previously sent campaigns with 1-click Re-send functionality.

## Deployment
Configured for zero-config deployment on Vercel or any static hosting platform.
